How It Works

Five-Stage OSINT Pipeline

🧠
1. Query Parsing
Splits input into first name, last name, keywords & location for targeted searching
🌐
2. Search Mashup
Queries DuckDuckGo with multiple query variants for broad web coverage
📡
3. Social Probing
Probes GitHub, Reddit, Wikipedia, LinkedIn, Twitter, Instagram & more
🔗
4. Entity Resolution
Deduplicates results, builds TF-IDF tag cloud & detects homonyms
📊
5. PeopleRank™
Computes a 0–100 online visibility score based on breadth, depth & authority

⚠️ IntelFusion searches only publicly available information. This tool is intended for educational and legitimate investigative use only. Do not use to harass, stalk, or harm individuals. Always respect privacy laws and platform terms of service.
